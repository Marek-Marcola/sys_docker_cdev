docker cdev
===========

Container development tools.

Build environments: docker, podman

Install
-------
Install:

    cdev.sh --inst -x
    -- or --
    cdev.sh --anpb -x
    -- or --
    cp -fv cdev.sh /usr/local/bin
    cp -fv cdev.env /usr/local/etc
    cp -fv zlocal-cdev.sh /etc/profile.d

Verify:

    cdev.sh --ver

Help:

    cdev.sh --help
